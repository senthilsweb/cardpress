A background is the artwork behind the card's text.

Choose one

  1. Open Design → Background and press Browse backgrounds.
  2. Pick a category on the left, or search.
  3. Select a background. Each one is shown on the current card.
  4. Press Use. Cancel changes nothing.

Search

Search by name, occasion or wish, for example thanks, deepavali, new year or lunar.

Use matching colours applies the colour set along with the background. Switch it off to keep the current colours.

Greeting words

Choosing a background never changes the text. Type the greeting in Headline, or ask in Chat, for example "give me three Diwali greetings for the headline".

Backgrounds with images

Photo mosaic, Browser frame and Own image need a picture, added under Design → Images.
