# Frame and themes

## ADDED Requirements

### Requirement: Navigation is named
#### Scenario: The side bar
- **WHEN** a page is open
- **THEN** each item shows an icon and its name, and the open one is marked

### Requirement: A person chooses the colours
#### Scenario: Aubergine
- **WHEN** a person picks Aubergine under Appearance
- **THEN** the application changes at once, stays so on their next visit, and no card changes colour
