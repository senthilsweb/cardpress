# Studio

## ADDED Requirements

### Requirement: One place for an item
#### Scenario: Editing
- **WHEN** the person opens Details
- **THEN** every writable field of the item on screen is there once

### Requirement: Status always visible
#### Scenario: Anywhere in the form
- **WHEN** the person is anywhere in Details
- **THEN** the status, what is missing and the next action are visible without scrolling

### Requirement: One way to start
- **WHEN** the person looks for a way to start over
- **THEN** there is one New button, above the canvas
